# ENG-0002.rule-independent-motion-engine

## Rule

Алгоритм Edge Motion реализуется на Swift как независимо тестируемый детерминированный движок, не зависящий от macOS APIs. Контакты, время и состояние, необходимое для решения, поступают через явные входы; воспроизведение одинаковых входов даёт одинаковые решения.

## Applicability

Conditional

## Applies when

- Изменяются алгоритм Edge Motion, state machine, оценка скорости/направления, motion profile либо границы движка.

## Rationale

ТЗ требует проверять алгоритм синтетическими или записанными кадрами без зависимости от физического оборудования и платформенных APIs.

## Guidance

Платформенный input и injection находятся за границами алгоритма. Движок получает стабильные внутренние кадры, а не private ABI. Не фиксируются приведённые в источнике имена классов, структура файлов, коэффициенты фильтра или формула acceleration: это примеры, а не отдельные обязательные решения.

## Verification

Активация, hold, гистерезис, steering, suppression и release воспроизводятся на синтетическом вводе без запуска macOS input backend и публикации системных событий. Время воспроизведения управляемо, результаты повторяемы.
