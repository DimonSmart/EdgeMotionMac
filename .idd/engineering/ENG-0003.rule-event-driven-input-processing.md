# ENG-0003.rule-event-driven-input-processing

## Rule

Доставка raw touch input строится на callbacks, без периодического опроса трекпада. Callback копирует минимально необходимый кадр и отделён от UI и обработки движком. В callback запрещены UI calls, disk I/O, логирование каждого кадра, дорогие allocations и ожидание locks, удерживаемых UI.

## Applicability

Conditional

## Applies when

- Изменяются доставка или обработка touch frames, потоки, очереди, timers или scheduling Edge Motion.

## Rationale

ТЗ требует предсказуемых задержек, сохранения последовательности кадров и низкого энергопотребления без зависимости callback от UI.

## Guidance

Передача кадров отделяет input callback от последовательной обработки алгоритмом. SPSC/ring buffer — рекомендация источника, а не закреплённая структура. В Idle/Tracking нет periodic timer; Armed допускает одноразовый hold; Active использует отдельный motion timer, выключаемый при stop. Частоты и бюджеты определены в IDD-0005.

## Verification

Input callback не выполняет запрещённых операций и не ждёт UI. Idle не создаёт periodic polling, hold не требует постоянного цикла, а остановка выключает motion timer. Измерения подтверждают latency и CPU budgets на целевой аппаратуре.
