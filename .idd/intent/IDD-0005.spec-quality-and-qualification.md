# IDD-0005.spec-quality-and-qualification

## Intent

Задать измеримые критерии отзывчивости, отсутствия ложных срабатываний и надёжности на заявленной платформе.

## Related Specifications

- IDD-0001 — целевая область поддержки.
- IDD-0002 — поведение алгоритма.
- IDD-0004 — эксплуатационные свойства.
- IDD-0007 — исходный feasibility gate.

## Behavior

| Метрика | Acceptance target |
| --- | --- |
| Input → decision p50 | < 4 ms |
| Input → synthetic event p95 | < 12 ms |
| Stop latency | < 20 ms |
| Active cursor update | 60–120 Hz |
| Idle CPU | < 0.3% typical |
| Active CPU | < 2% typical |
| Idle periodic polling | 0 |
| Persistent touch history | 0 |
| Memory | < 60 MB |
| False activation | < 0.1/hour обычной работы |
| Missed intentional activation | < 2% controlled tests |

Движение обновляется минимум с 60 Hz; 120 Hz предпочтительны для high-refresh display. Эти числа — цели продукта, а не утверждение об уже достигнутых свойствах macOS или реализации. Условия измерения typical CPU, памяти и latency, а также controlled test protocol требуют уточнения до заявления о выполнении бюджетов.

## Product-Significant Architecture And Constraints

В Idle/Tracking отсутствует постоянный polling и display-rate loop; в Armed допустим одноразовый hold timer. Периодический motion timer работает только в Active и выключается при остановке. Закрытые настройки не поддерживают активную debug visualization.

## Non-goals

Подмена аппаратной квалификации unit tests или объявление поддержки по факту успешного запуска приложения.

## Acceptance Criteria

Поддержка macOS 11–14 проверена на Intel и Apple Silicon во всех реально доступных и поддерживаемых аппаратурой комбинациях. Для встроенного трекпада обязательны обе архитектуры; Magic Trackpad Bluetooth/wired квалифицируется отдельно по ревизиям. В матрицу входят внешняя мышь и трекпад, несколько мониторов и Retina/non-Retina.

Выполнены важные функциональные сценарии: медленный и быстрый подход, диагональ и угол, неподвижное удержание после активации, уход внутрь и отрыв, второй палец, scroll/pinch/Mission Control, resting thumb без ложной активации, left-button drag, sleep/wake, reconnect и отзыв разрешения. Для выбранного guard отдельно проверяется отмена внешним вводом.

Длительная проверка включает 8 часов обычной работы, 10 000 activation/deactivation cycles, 1000 sleep/wake cycles с автоматизацией там, где практично, быстрые reconnect и повторные изменения permissions.

## Verification

Алгоритмические инварианты проверяются воспроизведением синтетических либо специально подготовленных тестовых данных, независимо от macOS APIs. Это не разрешает постоянный сбор пользовательской истории касаний.

Реальное оборудование необходимо для ABI, gestures, drag, разрешений, энергопотребления, display layout и lifecycle. Измерения должны включать latency распределения, CPU idle/active, память, ложные и пропущенные активации с указанием условий. Длительные проверки подтверждают отсутствие зависшего движения и деградации ресурсов.
