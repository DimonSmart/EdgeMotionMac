# IDD-0004.spec-platform-and-privacy

## Intent

Обеспечить безопасную работу пользовательской утилиты с минимальными разрешениями, предсказуемым lifecycle и проверенной доставкой.

## Behavior

### Разрешения и privacy

Accessibility/PostEvent нужны для synthetic cursor events. Статус проверяется до включения и во время работы; при отсутствии или потере доверия ввод и synthetic cursor events безопасно останавливаются. Системный запрос доступа выполняется только после явного действия пользователя; пассивная проверка статуса не показывает запрос. Input Monitoring не запрашивается для базового Edge Motion «на всякий случай»: запрос допустим только при включении функции, реально слушающей системный ввод.

Работа не требует сети. Запрещены telemetry raw touch coordinates, постоянная запись touch history, запись keyboard events и полных event streams. Если применяется crash reporting, допустимы OS version, hardware model, architecture, состояние алгоритма и error code; последовательности координат и keyboard input исключаются.

### Устройства и сессия

Несколько устройств перечисляются и различаются по идентичности; обрабатываются отключение и повторное подключение. Поддержка конкретных Magic Trackpad revisions, Bluetooth и wired подтверждается отдельно. Состояние контактов разных устройств не должно смешиваться.

При sleep, lock, потере разрешения и отключении устройства добавляемое движение прекращается. После wake/reconnect ввод восстанавливается через повторное обнаружение устройств, без продолжения устаревшей Active-последовательности.

Неизвестный ABI, отсутствующий framework/symbol или неподдерживаемый трекпад отключает Edge Motion безопасно. Обычный ввод macOS сохраняется; работа только в собственном окне не выдаётся за полноценную system-wide функцию.

### Доставка

Приложение работает без App Sandbox в интерактивной пользовательской сессии; не требует root daemon, privileged helper, модификаций /System, установки kext, замены драйвера или отключения SIP.

Release распространяется вне Mac App Store через GitHub Releases без Developer ID-подписи и notarization, в формате universal `.app` (arm64 + x86_64). На релиз публикуется SHA-256, Homebrew Cask генерируется и обновляется в этом же репозитории. Нужны upgrade path и документация о permissions, privacy, ограничениях private API и предупреждениях Gatekeeper. Опциональный Homebrew-установщик может явно уведомлять пользователя и удалять `com.apple.quarantine` только с установленного `EdgeMotion.app`, без глобального отключения Gatekeeper или SIP.

Self-update использует существующий Homebrew Cask и проверяет latest stable release по публичному GitHub API. Доступен только для подтверждённого Homebrew-managed `/Applications/EdgeMotion.app`. Перед изменением пакета выполняются `brew update`, проверка версии Cask, сравнение с GitHub Release. Задержка публикации Cask не приводит к установке старой версии. Только после этого выполняется targeted `brew upgrade --cask --no-quit --appdir=/Applications edgemotion`. Отмена возможна до изменения пакета, но не во время `brew upgrade`, проверки версии и подготовки перезапуска. Версия проверяется по `Info.plist`, quarantine удаляется только с `/Applications/EdgeMotion.app`, затем перезапускается новый экземпляр; прежний экземпляр прекращает touch-input и Quartz-output до запуска нового. Если обновление не удалось, старый экземпляр остаётся работающим; после неудачного relaunch ввод остаётся безопасно выключен. Автообновление не загружает и не распаковывает release ZIP самостоятельно, не требует root и не отключает Gatekeeper/SIP глобально.

Launch at Login доступен на целевых ОС. Необходимая поддержка macOS 11/12 является явно заданной совместимостью продукта; способ регистрации для этих ОС не фиксируется этим импортом.

### Дополнительные интеграции

Universal Control проверяется на совместимость; EdgeMotion генерирует обычное движение и не реализует собственный переход между машинами. Настройка отключения у display transition рассматривается только при подтверждённом конфликте.

Если впоследствии выбран enhanced external-input guard, физическое перемещение мыши, wheel и кнопка внешнего указателя отменяют Edge Motion. Собственные synthetic events должны различаться с физическими, чтобы не отменять себя. Мониторинг требует соответствующего разрешения и не должен без необходимости фильтровать или изменять системный поток.

## Product-Significant Architecture And Constraints

Единственная допустимая неподдерживаемая Apple часть выбранного решения — чтение raw multitouch contacts. Алгоритм, UI, lifecycle, output и distribution используют публичные API. Неподписанный и не нотариализованный статус приложения явно раскрывается; успешная публикация не доказывает совместимость private ABI.

## Non-goals

Снижение security posture пользователя, обязательное наблюдение клавиатуры, сетевой сервис для базовой работы и гарантия поддержки непроверенной OS/hardware combination.

## Acceptance Criteria

Release публикуется с SHA-256 и Homebrew Cask, устанавливается без SIP changes и root; отсутствие Developer ID-подписи и возможные действия пользователя при блокировке Gatekeeper документированы. Отказ/отзыв permissions и ошибки backend приводят к безопасному прекращению движения. Sleep/wake и reconnect восстанавливают работу без устаревшего продолжения. Privacy ограничения соблюдаются всеми diagnostics.

## Verification

Проверить явный запрос и пассивную проверку Accessibility, отказ и отзыв разрешения, безопасную остановку ввода и вывода, отказ загрузки и несовместимость ABI, подключение устройств, session lock, sleep/wake, несколько экранов, Universal Control, отсутствие чувствительных данных в diagnostics и публикацию GitHub Release, установку Homebrew, SHA-256, Gatekeeper и обновление. Квалификация выполняется на реальных поддерживаемых комбинациях из IDD-0005.
